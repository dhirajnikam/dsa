# Your learning path

[Start](README.md) · [Practice guide](PRACTICE.md)

Follow the **first lap** below. It is 23 exercises, not a deadline or a complete interview syllabus. One exercise can take several sessions. Each row links the theory and the actual task; the default runner follows this order, with due recall reviews first.

Before the NumArray task, linked lists, and trees, read chapter 01’s explanation of objects and references. You do not need to complete its whole exercise set. Learn extra Python tools when a task needs them.

## After the first lap

Use a chapter checkpoint to choose your next area. If you can explain, trace, and adapt the first problem, try another problem from that chapter. If not, revisit the relevant lesson. Add backtracking before advanced graph/DP problems. Add sorting keys, classes, deque, heapq, and caching from the Python chapters as needed.

The short path does not cover every interview pattern. Continue with recursion/backtracking, more binary search and tree variants, graph prerequisites/weighted paths, DP variants, and mixed mocks when ready. Advanced tries and caches can wait until your target interviews call for them.
